# 翡翠街 Jade Market Prototype

一个多人网页经营游戏原型。玩家在同一个本地服务器里参与翡翠公盘、加工经营、NPC 订单、收藏、直播和玩家交易。

## 当前核心流程

公盘竞拍 → 开料（opening）→ 规划取件（carving）→ 精加工（finishing）→ 藏品 / 订单 / 市场 / 直播

## 已实现的经营闭环

- 三阶段工坊：开料、规划取件、精加工。
- 每台设备容量永久固定为 1，同一设备不设等待队列。
- 设备商店：购买多个设备实例、固定 1 阶属性、耐久消耗与付费维修。
- 员工系统：候选刷新、招聘、最多 8 人、跨工坊/直播占用、经验与技能升级。
- 精加工镶嵌：成品类型、六种镶法、四种金属、三种配石、抛光与底托选择。
- 原子结算：开工时预占材料并支付人工费；组合无效、材料不足或现金不足不会产生部分扣款。
- 精加工失败会退回翡翠和镶嵌材料，人工费保留为已发生支出，设备耐久与员工经验正常结算。
- 藏品、订单和交易行统一显示成品镶嵌工艺摘要。

桌面端保留原有整体排版，已验证 1280×720 与 1440×900；移动端复用同一套 DOM，已验证 390×844 与 430×932。

## 启动方式

先安装依赖：

```bash
npm install
```

启动本地服务器：

```bash
npm start
```

然后打开：

```text
http://localhost:3000
```

## 验证

```powershell
npm test
npm start
```

`npm test` 会依次覆盖经营循环、公盘、服务端离线结算、任务、设备、员工、镶嵌、规则、渲染、开料、体积、画布、简化流程、弹窗和响应式布局。

## 项目结构

```text
server.js              后端游戏服务器和核心结算逻辑
server/systems/        设备、员工和镶嵌规则模块
public/index.html      页面结构
public/main.js         前端交互和渲染逻辑
public/*-module.js     各经营界面的独立渲染与交互模块
public/styles.css      UI 样式
scripts/*-smoke.mjs    自动化冒烟与回归检查
docs/design-plan.md    当前游戏设计方案
docs/project-notes.md  后续开发说明
```

## 当前技术

- Node.js
- Express
- Socket.IO
- 原生 HTML/CSS/JavaScript

## 重要说明

这是原型版本，数据目前只保存在服务器内存里。服务器重启后，玩家资产、库存和市场会重置；当前尚未接入数据库、正式账号与鉴权系统、持久化迁移、生产级监控和多进程一致性方案。
