## 1. 游戏概述与设计支柱 {#1}

### 1.1 一句话描述

一款以翡翠行业为背景的硬核放置经营模拟游戏。玩家自由组合"拍原石→切石→加工→销售"的全产业链行为，在赌石风险与经营策略之间寻找平衡，从无名小贩成长为翡翠泰斗。**无新手保护，资源紧张是常态，玩家需要自己解决生存问题。**

### 1.2 游戏类型

- **主类型**: 硬核放置经营模拟
- **副类型**: 赌石博弈 + 异步多人市场
- **多人模式**: **异步多人**，玩家不需要同时在线

### 1.3 设计支柱

| 支柱 | 描述 | 检验标准 |
|------|------|----------|
| **赌性即人性** | 切石的未知性是核心多巴胺引擎，但提供信息获取手段降低纯赌徒困境 | 玩家每次切石都有"能不能出好东西"的期待感，但不觉得纯靠运气 |
| **自由即深度** | 所有赚钱动作模块化，玩家随时切换和叠加，无强制成长路径 | 三个典型玩家路径至少能稳定跑通 |
| **声望即一切** | 声望是解锁内容、吸引客户、市场排名的唯一维度 | 高声望玩家切实感受到与低声望玩家的待遇差异 |
| **社交即市场** | 玩家间交易是经济核心而非附属，信息不对称创造套利空间 | 地摊、交易行、直播间三个渠道有明确的供需差异 |
| **硬核无保护** | 资源紧张是常态，破产/卡住是玩家需要自己解决的问题，无新手保护无经济保底 | 玩家会因为决策失误而"卡住"，但需要能提供明确的"自救路径" |

**新增设计原则（硬核定位）**：

- **决策有代价**：每个决策都有风险，错误决策会导致资源损失
- **无自动救助**：游戏不会 because 玩家"卡住"而自动给资源
- **生存压力**：前期资源紧张，迫使玩家做出优先级选择
- **成就感来自克服挑战**：玩家因为自己解决了问题而感到成就，而不是因为游戏给了奖励

## 2. 时间与轮转系统 {#2}

### 2.1 设计决策（重大修订）

**采用统一现实时间，取消"游戏日"机制。**

#### 为什么取消"20分钟=1天"？

通过矛盾分析发现：
1. **时间粒度混乱**：加工的"10分钟"是现实时间还是游戏时间，原设计未明确
2. **"天"的概念失效**：加工需要1.5天（游戏时间），但1天=20分钟现实，导致"天"失去叙事意义
3. **放置玩家不习惯准点**：公盘要求准点在线，与放置类定位冲突

#### 修订后设计

**时间系统（统一现实时间）**

- 所有等待时间（加工/公盘/直播）都用**现实时间**
- **取消"游戏日"的机械限制**，改为**叙事包装**
- 具体时间设定：

| 操作 | 时间（现实时间） | 说明 |
|------|------------------|------|
| 粗加工 | 5分钟 | 缩短，让玩家能更频繁地"收菜" |
| 精加工 | 15分钟 | 主要等待时间，但可以离线进行 |
| 镶嵌 | 5分钟 | 快速，外部材料到位后立即开始 |
| 公盘轮次 | 每现实1小时一轮 | 固定周期，玩家可预测 |
| 直播 | 10-30分钟（玩家设置） | 可长可短，支持自动模式 |
| NPC订单刷新 | 每现实4小时 | 固定周期 |
| 日刷新 | 每现实24小时（每日0点） | 叙事用，刷新登录奖励等 |

**"天"的叙事包装**

- 显示"第X天"（每现实1天=游戏内1天，按玩家当地日期计算）
- 显示"HH:MM"（游戏内时间，与现实时间无关，只是氛围营造）
- **不**用游戏内时间控制任何机制

**为什么这样改**

- 放置类玩家习惯用"现实时间"理解等待
- "天"作为叙事包装保留氛围，但不造成机制混乱
- 加工时间缩短到5-15分钟，玩家在一次上线期间可以完成多个操作

---

### 2.2 离线推进机制

**核心原则：所有时间基机制都支持离线推进。**

| 机制 | 离线推进 | 说明 |
|------|----------|------|
| 加工任务 | ✅ 支持 | 玩家下线后，加工继续 |
| 公盘竞价 | ✅ 支持 | 异步挂单，不需要在线 |
| 直播（自动模式） | ✅ 支持 | AI自动执行 |
| 直播（手动模式） | ❌ 不支持 | 需要玩家在线 |
| NPC订单 | ✅ 支持 | 订单倒计时离线继续 |

**上线时的处理**

- 玩家上线时，系统检查所有进行中的任务
- 更新进度（如果多个任务同时完成，按顺序播放动画）
- 显示"离线期间收益"汇总

---

### 2.3 时间相关刷新机制

**日刷新（每现实24小时，0点）**

1. **登录奖励**: 玩家上线时检查当日是否已领取
2. **市场趋势**: 某些品类热度变化（热门+15%售价/冷门-10%售价）
3. **NPC订单池**: 新一批NPC客户需求刷新
4. **工人日薪**: 自动从账户扣除所有雇佣工人的日薪
5. **设备耐久**: 所有切石/加工设备耐久度-1（耐久归零需维修）
6. **地摊NPC商品**: NPC摊主上架新一批原石/料子
7. **交易行到期**: 检查挂牌超过N天的商品，自动下架退回
8. **每日报告生成**: 自动生成当日经营报告（见第18章），可随时查看

**为什么保留日刷新**

- 日刷新是放置类游戏的常见设计，给玩家"新的一天"的感觉
- 刷新机制创造"上线收菜"的节奏感
- 但不采用"强制 day boundary"，玩家可以随时上线

## 3. 事件调度与刷新机制 {#3}

### 3.1 公盘周期（修订后）

**公盘频率：每现实1小时一轮**

```
公盘轮次 N（现实时间1小时）
═══════════════════════════════════════════════════════════

▸ 提前10分钟  公盘预告通知
                └─ 系统公告："第X届公盘将于10分钟后开启，本次原石清单：[列表]"

▸ 竞价阶段（30分钟，现实时间）
                ├─ 玩家随时可以浏览原石清单
                ├─ 玩家随时可以挂单出价
                ├─ 玩家可以设置"代理竞价"上限
                ├─ 出价后，如果有人出更高价，系统不会主动通知（避免要求在线）
                └─ 玩家可以主动查看"我的竞价"页面

▸ 公盘结束（竞价阶段结束后即时）
                ├─ 系统自动处理所有竞价
                ├─ 公布结果（系统消息）
                ├─ 中标者：保证金自动抵扣货款，需在规定时间内（现实1小时）补足差价
                ├─ 未中标者：保证金全额退还
                └─ 中标原石：付款后立即进入库存

▸ 下次公盘预告（结束后即时）
                └─ 系统公告："下一届公盘将于X分钟后开启"
```

**关键改动**

- 取消"报名阶段5分钟+竞价阶段5分钟"的实时机制
- 改为"竞价阶段30分钟"，玩家随时可以出价
- 增加"代理竞价"机制，玩家可以设置最高出价，系统自动加价

---

### 3.2 典型时间线（修订后）

**玩家的典型游戏日（现实时间）**

| 时间 | 事件 |
|------|------|
| 0分钟 | 玩家上线，收菜（查看离线期间完成的任务） |
| 2分钟 | 安排加工任务（如果有原石和空闲工人） |
| 5分钟 | 参加公盘（浏览原石，挂单出价，设置代理竞价上限） |
| 10分钟 | 粗加工完成（如果安排了），安排精加工 |
| 25分钟 | 精加工完成（如果安排了），售卖或继续加工 |
| 30分钟 | 玩家完成一个"循环"，可以下线，或开始下一个循环 |

**关键**：玩家一次上线25-30分钟，可以完成一个完整循环。如果玩家只有10分钟，他可以安排加工后下线，下次上线收菜。

---

### 3.3 加工时间线（修订后）

**全链路时间（现实时间）**

```
0分钟    获得原石 → 提交切石（5-60分钟，取决于原石等级）
5分钟    切石完成 → 获得料子
           → 【可卖 Stage 2】立即变现（挂地摊/交易行）
           → 提交粗加工（5分钟）

10分钟   粗加工完成 → 获得毛坯
           → 【可卖 Stage 3】半成品变现
           → 提交精加工（15分钟）

25分钟   精加工完成 → 获得成品
           → 【可卖 Stage 4】完整品变现（交易行/直播/NPC订单）
```

**设计含义**：全链路25分钟（现实时间）。着急的玩家5分钟就能卖料子走人，耐心的玩家等25分钟出成品追求最大利润。

## 5. 公盘拍原石 {#5}

### 5.1 设计理念（暗拍机制）

公盘是游戏中最核心的定时事件，也是原石进入玩家生态的最主要入口。

**核心设计决策**

| 维度 | 设计决策 |
|------|----------|
| 竞价模式 | **密封投标（暗拍）** — 出价期间看不到他人出价 |
| 时间模式 | 每现实1小时一轮，投标阶段30分钟（随时可修改出价） |
| 开标方式 | 投标结束后系统一次性公布结果（最高价者得） |
| 参与保障 | 出价人数<3人时AI买手自动补位，确保永远能开盘 |
| 信息博弈 | 投标前可选"开窗"获取原石部分信息（付费） |
| 费用结构 | 保证金（可退）+ 可选开窗费 |
| 离线支持 | 完全支持离线，投标期间不需要在线 |

**为什么用暗拍**

- ✅ **行业真实感**：现实翡翠公盘就是暗拍（密封投标，同时开标）
- ✅ **赌性最大化**：出价前完全不知道别人出多少，开标瞬间才知道结果 — 这才是"赌石"的精髓
- ✅ **策略深度**：需要判断"别人会出多少"，而不是简单地"比当前价高一点"
- ✅ **硬核定位**：符合硬核玩家喜欢的"高风险高回报"体验
- ⚠️ **新手门槛**：新手容易高估或低估，但这正是硬核游戏的一部分

---

### 5.2 暗拍流程

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────┐
│ 公盘预告      │ → │ 投标阶段      │ → │ 等待开标      │ → │ 开标公布  │
│ 提前10分钟   │   │ 30分钟        │   │ 0分钟         │   │ 即时     │
│ 看原石清单   │   │ 密封出价      │   │ 不能修改      │   │ 一次揭晓 │
│ 决定是否参加 │   │ 可随时修改    │   │              │   │          │
└──────────────┘   └──────────────┘   └──────────────┘   └──────────┘
```

#### 阶段一：公盘预告（提前10分钟）

- 系统公告："第X届公盘将于10分钟后开启，本次原石清单：[列表]"
- 玩家可以提前浏览原石，决定要竞拍哪些
- 原石清单显示：名称、重量、场口、底价、稀有度
- **不显示**原石内部品质（需要开窗才能获得部分信息）

#### 阶段二：投标阶段（30分钟，现实时间）

**密封出价**

- 玩家提交密封出价（看不到别人的出价）
- 出价时，系统扣除保证金（底价的20%）
- 投标期间，玩家可以**随时修改自己的出价**（覆盖上一次出价）
- 修改出价时，新的保证金覆盖旧的（多退少补）

**代理投标（暗标模式）**

```
玩家设置：
- 目标原石：老场口原石#1047
- 代理上限：15,000翠币（系统不会替你出超过这个价的价）

系统暗标执行：
- 系统记录你的代理上限
- 开标时，系统自动用"刚好赢"的价格成交（当前最高其他出价 + 最小加价幅度）
- 如果你的代理上限 < 其他玩家最高出价，你未中标，保证金退还
```

**为什么需要代理投标**

- 放置类玩家可能忘记在30分钟窗口内出价
- 代理投标让玩家可以"设置上限后不管"，符合放置类体验
- 保留赌性（不知道能不能中，开标才知道）

**开窗机制（投标前使用）**

- 花费目标原石底价的10-30%（按场次等级递增）
- 开窗位置由系统随机决定，玩家不能指定位置
- 开窗揭示该位置约20-40%的真实品质信息
- 同一块原石可多次开窗（上限3次），但信息增量递减
- **开窗只在投标前有效**，一旦提交出价就不能再开窗

**查看投标状态**

- 玩家可以查看"我的投标"页面
- 显示：我的出价、保证金扣除情况、剩余时间
- **不显示**当前最高价、出价人数、是否领先（这是暗拍！）
- 这个设计增加了心理紧张感：你永远不知道自己能不能中

#### 阶段三：等待开标（投标结束后，即时开标）

- 投标阶段结束后，系统立即开标
- 玩家不需要在线等待（但可以在线看开标动画）

#### 阶段四：开标公布（即时）

- 系统一次性公布所有原石的投标结果
- 每块原石：最高出价者中标（如果多人同价，先出价者得）
- 中标者：保证金自动抵扣成交价，不足部分从账户扣除
- 未中标者：保证金全额退还
- 流拍原石（无人出价）：系统回收，进入下次公盘或地摊NPC商品池

**开标动画（增加仪式感）**

```
屏幕显示：
┌─────────────────────────────────────┐
│  第X届公盘开标结果                    │
├─────────────────────────────────────┤
│  原石#1047（老场口，2.3kg）           │
│  出价人数：5人                        │
│  最高出价：15,000翠币                 │
│  中标者：玩家A ████                  │
│                                      │
│  [下一件]                            │
└─────────────────────────────────────┘
```

- 每件原石依次揭晓，增加紧张感
- 玩家可以分享开标结果到聊天频道

**如果中标者余额不足支付尾款**

- 保证金没收
- 原石流向下一个出价者（如果有）
- 如果无其他出价者，则流拍

### 5.5 边界情况

- **玩家余额不足支付尾款**: 保证金没收，原石流向下一个出价者；若无其他出价者则流拍
- **离线时中标**: 原石自动进入仓库，尾款自动扣除。余额不足按上条处理
- **修改出价**: 投标期间可随时修改，新的保证金覆盖旧的（多退少补）
- **同价处理**: 如果多人出价相同，先出价者得
- **代理投标上限被超越**: 开标时自动判定未中标，保证金退还
- **流拍**: 无人出价的原石，系统回收后进入下次公盘或地摊NPC商品池

### 5.6 暗拍的心理设计

**核心体验：赌性即人性**

暗拍的设计目的是最大化"赌"的体验：

1. **信息不透明**：出价期间看不到任何人的出价，只能靠自己的判断
2. **开窗博弈**：花钱开窗获取部分信息，但可能反而误导决策
3. **开标紧张感**：开标前永远不知道自己能不能中，这种不确定感就是"赌"
4. **结果冲击力**：开标瞬间知道结果，赢了兴奋，输了懊悔，情绪波动大

**与明拍的对比**

| 体验 | 暗拍（当前） | 明拍（v2.0） |
|------|-------------|-------------|
| 刺激时刻 | 开标瞬间 | 每次出价后 |
| 策略重点 | 判断别人会出多少 | 比当前价高一点 |
| 心理紧张感 | 高（全程未知） | 中（可以调整） |
| 新手友好度 | 低（容易高估/低估） | 高（跟着当前价走） |
| 硬核感 | 高 | 中 |

**设计取舍**

- 我们选择了"硬核感"和"赌性"，牺牲了"新手友好度"
- 这符合游戏的硬核定位
- 新手可以通过"多参加公盘"来积累经验（学习AI出价规律、其他玩家出价习惯）

## 9. 直播卖货系统 {#9}

### 9.1 设计理念（修订）

直播是高回报销售渠道，但**不强制玩家在线**。

**修订后设计**

| 维度 | 设计决策 |
|------|----------|
| 在线需求 | 手动模式需要在线，自动模式可以离线 |
| 收入方差 | 手动模式方差大（1.0~1.5），自动模式方差小（0.8~1.8但可控） |
| 操作需求 | 手动模式需要发送促销话术，自动模式不需要 |
| 硬核定位 | 手动模式给硬核玩家提供"操作感"和"更高收入"的可能 |

---

### 9.2 直播模式选择（新增）

玩家安排直播时，可以选择模式：

| 模式 | 说明 | 收入系数 | 操作需求 | 适用玩家 |
|------|------|----------|----------|----------|
| 手动模式 | 玩家在线，手动发送促销话术 | 1.0 ~ 1.5 | 高（需要在线） | 硬核玩家 |
| 自动模式（保守） | AI自动发送话术，优先稳定成交 | 0.8 ~ 1.1 | 低（离线可用） | 放置玩家 |
| 自动模式（激进） | AI自动发送话术，优先高价成交（可能卖不出去） | 0.9 ~ 1.8 | 低（离线可用） | 放置玩家（愿意承担风险） |

---

### 9.3 自动模式设计（新增）

**玩家选择模式后，直播自动进行。**

- 玩家选择模式和话术策略后，直播自动进行
- 系统根据主播属性、话术风格、选品质量，自动计算收入
- 直播结束后，系统消息通知玩家"直播已完成，收入XX翠币"

**话术策略（自动模式）**

| 策略 | 说明 | 收入范围 | 成交概率 |
|------|------|----------|----------|
| 保守 | 低价快速成交 | 0.8 ~ 1.0 | 90% |
| 均衡 | 平衡价格和成交率 | 0.9 ~ 1.2 | 70% |
| 激进 | 高价但可能卖不出去 | 1.0 ~ 1.8 | 40% |

**为什么这样设计**

- 自动模式让放置类玩家也能使用直播渠道
- 不同模式有不同的收入方差，玩家可以选择自己的玩法
- 自动模式收入略低于手动模式（但方差大），鼓励硬核玩家使用手动模式

---

### 9.4 手动模式设计（保留）

**硬核玩家可以选手动模式。**

- 玩家在线观看直播监控
- 可以发送促销话术（每场3次，增加收入）
- 可以提前结束直播（按已售出结算）

**促销话术**

- 玩家可以选择话术类型（限时优惠/讲故事/专业科普）
- 发送后，收入有一定概率提升

### 13.2 硬核设计：经济可能"卡住"

**设计意图**

- 如果玩家连续切出废料+公盘没中标+NPC订单收入低，他可能"没钱"
- 解决方案：玩家需要优化策略（比如先不做公盘，先做NPC订单积累资金）
- 游戏**不会**自动救助，玩家需要自己解决问题

**自救路径（明确）**

如果玩家"卡住"了（翠币=0，没有原石，没有订单），可以：

1. **等待NPC订单刷新**（每4小时刷新）
2. **完成NPC订单**（如果有订单）
3. **卖出库存**（如果有库存）
4. **向其他玩家借款**（如果有多人系统，待设计）
5. **重新开始**（如果实在没办法）

**为什么不提供保底**

- 硬核玩家的乐趣来自于"克服挑战"
- 如果游戏有保底，玩家不会感受到"资源紧张"的压力，也就不会感受到"成功"的喜悦
- 初始资源足够玩家开始，但不宽裕，迫使玩家做出**选择**

## 17. 风险评估与边界情况 {#17}

### 17.1 硬核风险（新增）

**风险：玩家可能因为决策失误而"卡住"，导致流失。**

**缓解措施**

1. **明确自救路径**：在教程中告诉玩家"如果没钱了，可以完成NPC订单"
2. **NPC订单保底**：NPC订单刷新频率足够高（每4小时），玩家不会长时间"卡住"
3. **社交救助**：如果有多人系统，玩家可以向其他玩家借款（待设计）
4. **叙事包容**：叙事上告诉玩家"经营有风险，失败是常态"，降低挫败感

**风险：经济循环可能断裂（玩家集体"卡住"）。**

**缓解措施**

1. **纸面测试**：用Excel模拟不同玩家路径，确保至少有一条路径能跑通
2. **NPC订单收入调整**：如果测试发现NPC订单收入太低，导致玩家无法"自救"，则提高NPC订单收入
3. **公盘保证金调整**：如果测试发现保证金太高，导致新手无法参与公盘，则降低保证金

## 19. 异步多人机制 {#19}（新增）

### 19.1 设计理念

**异步多人：玩家不需要同时在线，但能感受到其他玩家的存在。**

- 公盘：挂单竞价，不需要同时在线
- 排行榜：显示其他玩家的数据，但不需要同时在线
- 玩家收藏：玩家可以将自己的精品放入"收藏展示"，其他玩家可以查看
- 工坊参观：可选功能，玩家可以参观其他人的工坊（异步，看到的是快照）
