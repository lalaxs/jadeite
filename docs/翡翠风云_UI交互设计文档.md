## 1. 全局布局规范

### 整体结构

```
┌──────────┬──────────────────────────────────────┐
│          │  🏅 标题栏（页面名称 + 状态胶囊）      │
│  左侧     ├──────────────────────────────────────┤
│  导航栏   │                                      │
│  240px    │                                      │
│  固定     │  主内容区（可滚动）                    │
│          │  分组面板堆叠                          │
│          │                                      │
│          │                                      │
└──────────┴──────────────────────────────────────┘
```

### 左侧导航栏（常驻）

| 元素 | 规格 | 交互 |
|------|------|------|
| 游戏Logo | 顶部固定，24px金字 | 点击回到工坊总览 |
| 导航项（7个） | 图标36px + 主标题 + 副标题 | 点击切换页面，当前项金色左边框+背景高亮 |
| 玩家徽章 | 底部固定，头像+名字+Lv | 点击打开玩家详情弹窗 |

**导航项列表：**
1. 🏭 工坊总览 - 核心数据+工人+原石+加工进度
2. 🪨 公盘竞拍 - 报名/竞价/结果
3. ⚙️ 加工坊 - 粗加工/精加工/镶嵌任务管理
4. 💎 库存交易 - 四阶段货物展示+多渠道出售
5. 📡 直播卖货 - 主播管理+直播设置+实时销售
6. 🏅 声望殿堂 - 声望等级+解锁内容+排行榜
7. 📊 经营报告 - 每日/每周财务报表

### 顶部状态栏（常驻）

右侧显示 3 个状态胶囊 + 游戏时钟：
- 💰 翠币余额（点击快速充值/借款）
- 🏅 声望值（点击查看声望进度）
- 📦 库存数量（点击快速跳转库存页）
- 🕐 游戏时间（第X天 HH:MM）

### 内容区规范

- 内容按**分组面板**堆叠，同类信息放在同一个面板
- 面板结构：`面板头（标题+操作按钮）` + `面板体（卡片网格/列表/进度条）`
- 面板之间间距 24px
- 卡片网格：自适应列数，最小宽度 260px

## 页面01：工坊总览

> 入口：默认首页 / 点击Logo
> 定位：玩家每次上线第一眼看到的核心信息聚合页

### 页面目标

- 让玩家 10 秒内了解当前状态（有钱吗？有货吗？工人在干活吗？）
- 提供最快的行动入口（快捷操作区）
- 展示进行中的关键进度

### 内容分组（从上到下）

#### 分组1：核心资源面板

**目的：** 一眼看清最关键的四项数据

| 卡片 | 显示内容 | 交互 |
|------|----------|------|
| 💰 翠币 | 当前余额 + 今日收支变化 | 点击打开资金明细弹窗 |
| 🏅 声望 | 当前声望 + 距离下一级还需 | 点击打开声望进度弹窗 |
| 📦 库存 | 总件数 + 按阶段分布（原石/毛料/半成品/成品） | 点击跳转库存页 |
| ⏱️ 任务 | 进行中任务数 + 即将完成提醒 | 点击锚定到下方加工进度面板 |

**数值变化动画：** 收入时数字绿色向上滚动，支出时红色向下滚动

#### 分组2：快捷操作面板

**目的：** 最常用的6个操作，一键直达

| 按钮 | 跳转/操作 | 备注 |
|------|-----------|------|
| 🪨 参与公盘 | 跳转公盘页，并自动定位到当前轮次 | 如果公盘未开启则置灰提示"下一公盘：HH:MM" |
| ⚙️ 开始加工 | 跳转加工坊页 | — |
| 📡 开启直播 | 打开直播设置弹窗 | 需要先雇佣主播 |
| 🤝 NPC订单 | 打开NPC订单列表弹窗 | 显示3个当前可接订单 |
| 🏪 摆摊售卖 | 打开摆摊设置弹窗 | 选择要卖的货物 |
| 👷 雇佣工人 | 打开雇佣市场弹窗 | — |

**按钮状态：**
- 可用：金色边框+悬停发光
- 置灰不可用：降低透明度+waning提示
- 进行中（如直播已开启）：显示"进行中"标签，点击跳转直播页

#### 分组3：工坊工人面板

**目的：** 管理工人，查看状态和属性

**卡片结构（每个工人）：**
```
┌─────────────────────────────────┐
│  [头像]  工人名字  Lv.X          │
│          标签：老手/快手/细心...  │
│  ┌────┬────┬────┐              │
│  │技艺│速度│眼力│  (属性进度条)  │
│  └────┴────┴────┘              │
│  [分配任务按钮] [解雇按钮]       │
└─────────────────────────────────┘
```

**交互：**
- 点击工人卡片 → 打开工人详情弹窗（完整属性/工作历史/合同到期时间）
- 点击"分配任务" → 下拉选择任务类型（切石/雕刻/抛光/质检）
- 工人状态角标：
  - 🟢 工作中（显示当前任务名）
  - 🔵 空闲（可分配任务）
  - 🔴 疲惫（效率-30%，需休息）
  - 🟡 学习中（经验值+中，暂时不可工作）

**工人上限：** 初始2人，随声望等级解锁最多6人

#### 分组4：最新原石面板

**目的：** 快速预览最近获得的原石，刺激切石欲望

**卡片结构（每个原石）：**
```
┌─────────────────┐
│  [原石图片/图标]  │
│  稀有度标签       │
├─────────────────┤
│  原石名称         │
│  重量 │ 底价       │
│  [查看详情]       │
└─────────────────┘
```

**稀有度边框颜色：**
- 普通：灰色边框
- 良品：绿色边框
- 极品：金色边框 + 微光动画

**交互：**
- 点击原石卡片 → 打开切石确认弹窗（选择切石工人/预估风险/预期收益）
- 点击"查看详情" → 打开原石详情弹窗（皮壳表现/场口/重量/预估种水）

#### 分组5：加工进度面板

**目的：** 追踪所有进行中的加工任务

**进度条结构：**
```
任务描述文字                    65%
[████████████░░░░░░░░░░░░]      (渐变金色进度条)
预计完成：HH:MM   [加速] [取消]
```

**交互：**
- 点击进度条区域 → 打开任务详情弹窗（所用工人/耗时/消耗材料/预期产出）
- 点击"加速" → 消耗翠币立即完成（费用 = 剩余时间 × 10翠币/分钟）
- 点击"取消" → 二次确认后取消，返还50%已消耗材料

**进度条状态色：**
- 进行中：金色渐变
- 即将完成（<10%）：绿色脉冲动画
- 异常（工人疲惫/材料不足）：红色闪烁，悬停显示原因

## 页面02：公盘竞拍

> 入口：左侧导航 🪨 公盘竞拍
> 定位：游戏核心玩法，高风险高回报的赌石获取渠道

### 页面目标

- 清晰展示当前公盘轮次状态和倒计时
- 让玩家便捷地浏览/筛选/投标原石
- 提供竞价过程的紧张感和结果反馈

### 页面结构

#### 顶部：公盘状态横幅

```
┌──────────────────────────────────────────────────┐
│  📢 第XX届公盘 · 报名阶段                         │
│  距报名截止：HH:MM:SS  [立即报名]                  │
│  已报名：12人  总保证金：60,000翠币                 │
└──────────────────────────────────────────────────┘
```

**状态流转：**
1. **报名阶段（5分钟）** → 显示报名截止倒计时，点击"立即报名"缴纳保证金
2. **竞价阶段（5分钟）** → 显示竞价截止倒计时，展示可竞拍原石列表
3. **结算阶段（30秒）** → 显示中标结果，保证金退还/抵扣

**交互：**
- 报名按钮：点击后弹出确认弹窗（"缴纳保证金5,000翠币？报名后不可退出"）
- 倒计时：最后60秒红色闪烁，营造紧张感

#### 分组1：我的投标面板

**目的：** 查看自己已投标的石头和当前最高价

| 列 | 内容 | 交互 |
|----|------|------|
| 原石 | 缩略图+名称 | 点击查看原石详情 |
| 我的出价 | 我的当前出价 | 可编辑（竞价阶段） |
| 当前最高 | 实时显示最高价 | 自动刷新（3秒轮询） |
| 状态 | 领先/被超越/未中标 | 被超越时红色闪烁+提示音 |
| 操作 | 加价按钮 | 点击快速加价（+5%/+10%/+自定义） |

**加价交互：**
- 点击"+5%" → 出价 = 当前最高价 × 1.05，一键确认
- 点击"+10%" → 出价 = 当前最高价 × 1.10
- 点击"自定义" → 弹出输入框，手动输入出价金额
- **出价确认：** 二次确认弹窗（"出价XX翠币？确认后不可撤回"）

#### 分组2：公盘原石列表面板

**目的：** 浏览所有可竞拍的原石

**筛选/排序栏：**
- 筛选：全部 / 普通 / 良品 / 极品
- 排序：底价↑ / 底价↓ / 重量↑ / 重量↓ / 稀有度
- 搜索框：按原石名称搜索

**原石卡片（列表模式）：**
```
┌──────────────────────────────────────────────────┐
│ [图] 老场口原石#1047  普通  │ 重:2.3kg │ 底价:8,500 │
│ 当前最高价：9,200 (玩家A)  │ 我的出价：—           │
│                                         [我要投标] │
└──────────────────────────────────────────────────┘
```

**交互：**
- 点击原石行 → 展开详情（皮壳表现/场口信息/历史成交参考）
- 点击"我要投标" → 弹出投标弹窗（输入出价/确认）
- 已投标的原石：行背景高亮，显示"已投标"标签

#### 分组3：竞价结果面板（竞价结束后显示）

**目的：** 展示本轮公盘的中标结果

| 状态 | 显示 | 后续操作 |
|------|------|----------|
| 中标 | 绿色"恭喜中标！" + 原石详情 | "立即付款"按钮（保证金自动抵扣，补差价） |
| 未中标 | 灰色"未中标" + 原石详情 | 保证金全额退还 |
| 流拍 | 黄色"流拍" + 原因 | 无操作 |

**付款交互：**
- 点击"立即付款" → 弹出付款确认弹窗
- 付款成功后，原石自动进入库存（原石阶段）
- 如果翠币不足：显示"翠币不足，是否借款？"选项

## 页面03：加工坊

> 入口：左侧导航 ⚙️ 加工坊
> 定位：将原石加工为成品的核心生产系统

### 页面目标

- 清晰展示三阶段加工流程（粗加工→精加工→镶嵌）
- 让玩家便捷地派工和追踪进度
- 展示加工所需材料和外部材料

### 页面结构

#### 顶部：加工流程指示器

```
原石 → 粗加工 → 毛料 → 精加工 → 半成品 → 镶嵌 → 成品
 [当前阶段高亮]
```

**交互：** 点击任意阶段，快速跳转到该阶段的任务列表

#### 分组1：待加工队列面板

**目的：** 管理等待加工的原石/毛料/半成品

**队列卡片：**
```
┌──────────────────────────────────────────────────┐
│ [原石缩略] 老场口原石#1047                         │
│ 加工目标：手镯坯（粗加工）                          │
│ 所需工人：切石技能 ≥ Lv.3                          │
│ 预计耗时：10分钟                                    │
│ 状态：等待分配工人                                 │
│                              [分配工人] [取消任务] │
└──────────────────────────────────────────────────┘
```

**交互：**
- 点击"分配工人" → 弹出工人选择弹窗（只显示符合条件的空闲工人）
- 点击"取消任务" → 二次确认后取消，原石保留在库存
- 分配工人后：卡片移入"进行中任务"面板，开始进度条

#### 分组2：进行中任务面板

**目的：** 追踪所有加工任务的实时进度

**任务卡片：**
```
┌──────────────────────────────────────────────────┐
│ 🔨 粗加工：老场口原石#1047 → 手镯坯                │
│ 负责工人：老王 (Lv.5)                              │
│ 进度：████████████░░░░ 65%                         │
│ 预计完成：14:55                                    │
│ 消耗材料：金刚砂轮×1（已扣除）                       │
│ [加速完成] [取消]                                   │
└──────────────────────────────────────────────────┘
```

**多任务堆叠：** 同一阶段的多任务折叠显示（"粗加工任务 (3)"，点击展开）

**交互：**
- 点击任务卡片 → 打开任务监控弹窗（实时进度/工人状态/品质预测）
- 点击"加速完成" → 消耗翠币立即完成
- 点击"取消" → 二次确认，返还50%材料

**完成时的反馈：**
- 进度条满 → 播放完成动画（金色闪光）
- 弹出品质鉴定结果弹窗：
  - 显示成品品质（普通/良品/极品）
  - 显示加成（工人技能/外部材料/运气）
  - "收入库存"按钮

#### 分组3：外部材料面板

**目的：** 管理镶嵌阶段所需的外部材料

**材料卡片：**
```
┌──────────────────────────────────────────────────┐
│ 💍 18K金托                                         │

│ 用途：蛋面戒指镶嵌                                  │

│                     [购买] [自动补货设置]           │

```

**交互：**
- 点击"购买" → 弹出购买弹窗（选择数量/确认总价）
- 点击"自动补货设置" → 弹出设置弹窗（设定库存下限/自动购买上限）
- 材料不足时：镶嵌任务暂停，显示"等待材料"状态

#### 分组4：加工历史面板

**目的：** 查看过往加工记录，分析工人表现

**历史记录表格：**

| 时间 | 原石 | 加工类型 | 负责工人 | 产出品质 | 操作 |

**交互：** 点击"详情" → 打开加工详情弹窗（完整过程/品质分析/收益计算）

## 页面04：库存交易

> 入口：左侧导航 💎 库存交易
> 定位：货物管理和多渠道销售

### 页面目标

- 按四阶段清晰展示所有库存
- 提供三种销售渠道（黑市/交易所/直播）
- 让玩家便捷地定价和上架

### 页面结构

#### 顶部：库存概览 + 阶段切换

```
库存总量：47件  [原石 12] [毛料 8] [半成品 15] [成品 12]  → 阶段Tab切换
```

**阶段Tab交互：**
- 点击Tab → 下方列表切换到对应阶段的货物
- 当前阶段Tab：金色下划线 + 背景高亮
- 空阶段：Tab正常显示但列表显示"暂无库存"

#### 分组1：货物列表面板

**目的：** 展示当前阶段的所有货物

**列表视图 / 卡片视图切换：**
- 列表视图：信息密度高，适合大量货物
- 卡片视图：视觉效果好，适合精品展示

**货物卡片（卡片视图）：**
```
┌──────────────────────────────────────────────────┐
│ [图] 冰种手镯                                      │
│ 阶段：成品  品质：良品                              │
│ 成本：35,000  建议售价：52,000                      │
│ 获得时间：第6天                                     │
│ 状态：未上架                                        │
│            [上架售卖] [查看详情] [存入收藏]          │
└──────────────────────────────────────────────────┘
```

**交互：**
- 点击"上架售卖" → 弹出渠道选择弹窗
- 点击"查看详情" → 打开货物详情弹窗（完整属性/加工历史/成本明细）
- 点击"存入收藏" → 移入玩家收藏夹（不计入可售库存）

#### 分组2：上架售卖弹窗（核心交互）

**弹窗结构：**

```
┌──────────────────────────────────────────────────┐
│ 上架售卖：冰种手镯                                  │
├──────────────────────────────────────────────────┤
│ 选择销售渠道：                                      │
│ ○ 黑市摊贩（快速出手，价格-20%）                    │
│ ○ 交易所（挂牌等待，按建议价）                      │
│ ● 直播带货（高价潜力，依赖主播魅力）← 默认选中        │
├──────────────────────────────────────────────────┤
│ 定价设置：                                          │
│ 建议售价：52,000                                    │
│ 我的定价：[ 48,000 ] 翠币  (自定义输入框)           │
│ 预计收益：48,000 - 35,000(成本) = 13,000            │
├──────────────────────────────────────────────────┤
│ [确认上架]  [取消]                                 │
└──────────────────────────────────────────────────┘
```

## 通用交互规范

### 弹窗系统

**弹窗层级（从下到上）：**
1. 普通弹窗（确认/取消）
2. 详情弹窗（信息展示）
3. 设置弹窗（表单输入）
4. 全局通知（Toast，自动消失）

**弹窗交互规范：**
- 点击遮罩层：关闭弹窗（可选择是否允许）
- Esc键：关闭弹窗
- 确认操作：二次确认防止误操作
- 危险操作（解约/删除）：红色确认按钮 + 输入确认文字

### 反馈系统

**操作反馈：**
| 操作 | 视觉反馈 | 听觉反馈 |
|------|----------|----------|
| 成功 | 绿色对勾 + 淡入淡出 | 清脆"叮"声 |
| 失败 | 红色叉号 + 抖动 | 低沉"咚"声 |
| 进行中 | 进度条/加载动画 | — |

**通知系统（Toast）：**
- 位置：右上角堆叠
- 持续时间：成功3秒 / 警告5秒 / 错误8秒
- 类型：成功（绿）/ 警告（黄）/ 错误（红）/ 信息（蓝）

### 状态同步

- 翠币/声望/库存：实时显示，有变化立即更新

## 附录：交互流程图

### 核心流程1：从原石到售出

```
获得原石 → 切石（工坊总览）→ 粗加工（加工坊）→ 精加工（加工坊）
→ 镶嵌（加工坊）→ 成品入库（库存交易）→ 上架售卖（选择渠道）
→ 售出 → 翠币收入
```

### 核心流程2：公盘竞拍

```
查看公盘状态 → 报名（缴纳保证金）→ 等待竞价开始
→ 浏览原石 → 投标（出价）→ 竞价结束 → 中标/未中标
→ 付款/退保证金 → 原石入库
```

### 核心流程3：直播卖货

```
雇佣主播 → 安排排班（选品/时间/话术）→ 直播开始
→ 监控实时数据 → 发送促销话术（可选）→ 直播结束
→ 查看结算报告 → 收入到账
```
