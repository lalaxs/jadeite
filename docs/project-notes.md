# Codex 项目说明

## 项目目标

把“翡翠行业经营”做成一个可逐步扩展的多人网页游戏原型。当前重点不是画面最终品质，而是验证核心经营循环：

```text
拍原石 -> 角度切石 -> 明料 -> 切片 -> 规划分割 -> 成品经营
```

## 当前完成度

已完成：

- 本地多人服务器
- 公盘原石生成
- 原石矢量表现
- 玩家自定义切石角度
- 切石机等待
- 明料、片料、成品三段加工
- 片料规划板
- 手镯、珠串、无字牌
- NPC 订单
- 藏宝阁收藏
- 玩家交易行
- 市场战报

未完成：

- 账号登录
- 数据库存档
- 长期订单关系
- 更真实的竞价机制
- 更细的翡翠种、水、色、裂、棉、脏评分
- 移动端专门交互优化
- 正式部署

## 下一阶段建议

1. 接入本地 SQLite 或 PostgreSQL，保存玩家资产。
2. 把切石、切片、分割逻辑拆成独立模块，方便继续调参。
3. 加入真正的公盘竞价倒计时，而不是一口价拍下。
4. 给规划板增加拖拽手柄，替代滑杆微调。
5. 做一版新手引导，让玩家知道从哪里开始赚钱。

## 开发注意

- 后端权威：重要结算必须在 `server.js` 里完成，不能相信浏览器。
- 前端只做表现和操作意图提交。
- 当前没有数据库，所有状态都会随服务器重启丢失。
- 片料规划分割时，服务器会根据规划位置、尺寸、旋转和色裂关系计算成品价值。
