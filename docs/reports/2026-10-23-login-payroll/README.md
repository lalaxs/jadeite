# 登录日工资结算（已启用）

## 玩家规则

- 北京时间登录当天记录一份员工工资快照，下一个登录日结算上一份账单。10号登录、13号再登录，只收10号工资；11号、12号不记薪。
- 同一天刷新、重连、多窗口和服务重启均不重复记薪、扣款。新规则首次登录仅记账，不收旧日期工资。
- 持续在线跨天：首次安排工坊加工、开播、直播补货、招聘或解雇进入新营业日，先结上次记录日期，再记录当天。挂机、定时任务和被动/离线收入不触发新日期。
- 名册与日薪按记薪日保存快照；新员工加入当日账单，后续升阶不会改变历史金额。日薪数值保持100、140、190、250、320、400、490、590、700、820元，初始四人合计1500元。
- 解雇立即结清当天整日日薪并标记，次日不会重复收取。跨天直接解雇会先结上次登录日，再结离职当天，预览显示实际分次支付的合计金额。
- 资金不足整笔挂账，保留未扣现金；宽限一个实际营业日，离线不消耗宽限期。下一个营业日结算宽限日账单，仍未付清则当天停工、不新增工资。收入20%补薪、手动补薪和结清后主动复工保留；已有任务继续完成。
- 登录结算弹窗显示工资日期、员工明细、应计金额、实际扣款、扣后现金、待补工资。弹窗由存档中的待确认账单驱动；关闭只确认回执，不发起扣款。旧回执确认不能清掉较新的账单。

## 旧存档迁移

工资版本升级为3，政策版本2。旧存档不能可靠拆分在线与离线产生的欠薪，因此统一免除旧规则全部未付工资余额，保留现金、员工、已支付总额和历史流水，以`legacyDebtCleared`、`forgivenTotal`记录免除金额。旧工资时钟不再用于计薪，首次登录重新建账。迁移完成即持久保存，重复重启不会再次清理新规则欠薪。

实际迁移106名玩家、424名员工，其中101名玩家旧欠薪合计 **¥2,537,461** 已免除。逐玩家比对备份确认现金、员工名册、已付款总额及历史回执一致。无测试账号写入实际存档。
