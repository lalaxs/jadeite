# 镶嵌配件风格调整

本次调整对象是金属底座、扣头、镶爪、配石及材料图标的表面表现。

- 四种金属改用低对比、单向明暗，去除反复的镜面亮暗条带。
- 配石降低饱和度和反光强度，简化切面，保留石窝、金属压边与固定爪的覆盖顺序。
- 使用稳定的细颗粒程序纹理，作用范围限定在配件前后两层；玉件材质与抛光绘制保持原有逻辑。
- 商铺和库存中的金属、配石图标共用这套色板与表面纹理。
- 配件结构、配石排布、用料计算和历史成品规则沿用现有方案。

实现位于 `public/finished-product-renderer.js` 和 `public/inlay-product-renderer.js`。

验证：11 个相关检查脚本通过，包含成品布局、配石计数、用料、玉件渲染、原料取件保留、库存和架构检查。浏览器核对六种镶嵌的显示与绘制数量一致、四种金属颜色不同；玉件可见 SVG 绘制内容前后一致（忽略实例 ID 和记录元数据）。配件纹理未作用于玉件层。390×844 手机页面无横向溢出，浏览器无 error 日志。
