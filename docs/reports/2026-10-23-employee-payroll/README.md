# 员工工资：统一午夜结算与扣款提醒

## 原有行为

原实现使用 4 小时经营日，从每位员工各自的入职／计薪时间起算，满 4 小时扣一次日薪；解雇按任职时长折算。各员工扣款时间不一致，在线扣款缺少通知。

## 已实施规则

- 工资以北京时间（UTC+8）的自然日计算，每日 00:00 统一结清前一天工资，独立于经营日、测试加速模式和服务器时区。在线由每秒到期任务检查；离线及停服期间在恢复时补结算。
- 入职当天按整天计薪；1～10 阶自然日日薪调整为 100、140、190、250、320、400、490、590、700、820 元，不再乘以原来的 ×3 倍率。初始四名员工分别为 320、590、190、400 元，合计 1,500 元／天；闲置与离线照常计薪。
- 解雇立即结清该员工当天整日工资及此前未结工资，保留原有忙碌限制。当天即使刚入职也支付一天工资，已移除员工不会在午夜再次计薪。
- 欠薪处理已升级：余额不足时整笔挂账、保留现金，给予 24 小时宽限，经营收入按 20% 补薪，逾期停工后停止新增工资。手动补薪及复工详见 `../2026-10-23-payroll-arrears/README.md`。
- 旧 4 小时计薪存档首次迁移时重置未结工资的起点，保留已发生的累计工资、已付工资和欠薪，不按新规则追扣迁移前的时长。
- 本次日薪下调直接使用当前阶位工资表，旧存档中的工资缓存不能覆盖新数值；已有自然日结薪游标及历史流水继续保留。

## 玩家提醒

1. 员工页常驻下次结薪日期、北京时间 00:00、预计应付、当前现金和资金缺口，并解释整日计薪及解雇规则。
2. 23:30 起首次收到状态时显示一次轻量提醒。提醒区同时保留午夜工资事项和查看工资入口。刷新页面及重复状态推送不会重复弹出。
3. 结算或欠薪补扣后，显示应计工资、实际扣款、扣后余额及待补工资。离线恢复也可以收到此前尚未展示的结算通知。
4. 员工页保留最近 10 次工资记录，可展开每位员工的日薪、计薪天数、金额，以及原欠薪、本次已扣和余额。账单继续记录实际资金支出。
5. 招募详情说明结薪时间及当天工资规则；解雇确认显示当天日薪、本次应结、立即扣款、余额及剩余欠薪。
