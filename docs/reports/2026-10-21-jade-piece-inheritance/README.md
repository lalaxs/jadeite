# 精加工延续具体取件玉件

新取件物品保存独立的 `jadePiece` 底稿。工坊正常取件与黑市规划拆件共用捕获逻辑；后续预览、精加工、库存和交易绘制沿用底稿。

- 底稿保存玉件编号、来源、取件坐标与旋转、原料材质场、种水与瑕疵信息、具体轮廓及物理尺寸。显式保留 openingSeed，避免恢复时改用另一个随机来源。
- 材质场直接保存生成结果与渲染参数，取件完成后不再根据成品编号、名称或展示等级重新生成。保存恢复、来源原石移除和物品流转不会改变玉件。
- 毛坯与成品共用玉料绘制。精修增加题材细节，抛光根据原件种水调整表面光泽；原料种水与加工工分分别保留。
- 镶嵌沿固定轮廓装配。配石沿用现有石座规则；新底稿物品的金属用量按实际尺寸缩放，客户端报价与服务端扣料共用规则。原件过大的蛋面无法缩小为戒面；已知厚度不足时禁用戒托。
- 新底稿物品的编绳使用绕边连接，保留原有孔洞，不在渲染阶段凭空打孔。手镯按所选内径确定物理尺度。
- 精加工页面支持同角度、同倍率前后对照及隐藏配件；切换方案保留隐藏配件和来源展开状态。库存详情可回看原貌和来源原石上的取件位置。
- 旧物品和已保存任务沿用现有数据、外观与用料规则，不批量重新生成。缺少历史底稿的物品明确提示记录限制；没有测量厚度时不显示虚构厚度。
