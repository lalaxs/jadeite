# 佛公镶嵌边缘重叠修复

2026-10-22

微镶原来同时绘制贴玉底座、前侧边框和配石底圈。佛公完整底框图片还叠加了随形边条，两种轮廓不完全一致，头部和肩部因此出现双边缘。

现在微镶只绘制一圈连续底座，覆盖原玉边缘与配石区域。佛公使用现有手绘金属边条的窄截面沿原件轮廓贴合，不再叠加另一张轮廓不同的完整底框；闭合边条增加采样，避免横向笔触被挤成重复条纹。金属图片、玉件材料、配石数量和结算规则沿用原数据。

已通过 `inlay-artwork-smoke`、`finished-product-design-smoke`、`jade-piece-smoke`、`inlay-preview-tester-smoke`。现有素材检查新增了未选配石与已选配石两种微镶状态的单圈验证。

浏览器确认金色、银色空底座以及 60 颗钻石的微镶状态；同时检查佛公包镶与蛋面微镶的共用渲染。
