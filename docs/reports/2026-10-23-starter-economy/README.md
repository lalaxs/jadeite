# 新手经济调整与流程验收

日期：2026-10-23。

## 已实施规则

- 新账号初始现金为 **12,000 元**，仅赠送 **1 块原石**；先按糯种 70%、豆种 30% 抽取品质，再生成对应原石。
- 赠送原石重量限制为 0.8–1.1 kg，参考价约 1,900–4,700 元；筛选可用的开料图，避免赠送稀有高价颜色。筛图不会重新抽取种水。
- 原账号保留现金和物品；刷新、重连、原石用完后不会重复补发。新规则不会重置存档。
- 赠送原石及其衍生材料在原主人加工失败时返还本阶段投入，仍消耗加工时间和设备耐久；普通进货原料不享受此保护。
- 首件赠送料成品领取后生成匹配的“街坊试单”，订单收入为货值的 1.12 倍。普通订单增加最低货值要求，含小费总收入上限为交付货值的 1.25 倍。
- 新手阶段任务与成就现金奖励共享 1,000 元额度，日常任务现金另有每日 1,000 元上限；经验等奖励不变。降低重复操作任务的现金奖励。
- 新手拍卖入场费降至 200 元。成品 NPC 收购维持估值 65%，每位卖家每日最多 6,000 元、4 件，挂单等待时间仍为 10 分钟；报价会预占额度。
- 收紧直播高溢价的 AI 购买概率；报价达到估值 1.5 倍后，包含主播、声望加成的最终单次购买概率不超过 3%。
- 周转借款改为主动申请，要求已有经营记录并完成新手进货循环，保留原有债务、资产与冷却限制。大额购买增加购买后余额与周转储备提示。

## 真实浏览器完整流程

通过 Playwright 操作实际页面、画布、加工设备、领取弹窗、订单交付和进货界面。使用隔离的临时服务器，关闭持久化；测试时间配置仅加速加工计时，没有注入现金、原料或成品。

| 阶段 | 结果 | 现金余额 |
| --- | --- | ---: |
| 新账号领取资源 | 12,000 元 + 1 块原石 | 12,000 元 |
| 开料、排版雕刻、绳饰加工、领取成品 | 成品估值 2,113 元，无额外材料支出 | 12,000 元 |
| 交付街坊试单 | 收入 2,367 元 | 14,367 元 |
| 再次进货 | 买入 1,858 元原石 | 12,509 元 |
| 刷新重连 | 余额、进货原石保持一致，没有重复赠送 | 12,509 元 |

浏览器页面异常数为 0；检查了桌面 1440×1000 和手机 390×844 页面截图。测试发现并修复了减少动态效果模式下，领取弹窗调用动画取消方法时报错、无法正常收起的问题。

以上金额是本次随机样本的真实记录，并非每位新手固定收入。原始结果见 [browser-flow.json](./browser-flow.json)。

## 回归与边界验证

- 主测试入口展开后的 **89 组测试全部通过**，各组退出码和输出见 [regressions.json](./regressions.json)。本机没有可直接调用的 npm，实际使用 Node 执行对应脚本。
- 10,000 个均匀分位输入验证品质边界，结果为糯种 7,000、豆种 3,000；另生成 100 块真实原石，验证筛图后种水不被重抽、重量和参考价受限。这是概率映射验证，不是宣称任意随机样本都精确符合 70:30。
- 糯种、豆种各完成一轮服务端加工、出售、再次进货；强制覆盖开料失败、雕刻失败，检查返料、设备损耗、工人释放和排版几何恢复。
- 验证首次奖励总额上限、跨日重置、持久化数字恢复、低价货不能交付高价订单、买入原料不受新手返料保护、无经营记录的新号不能申请借款。
- 30 个模拟日与反复 SQLite 重启的运行测试通过。该项首次批量运行因 120 秒任务期限中断，随后独立完整执行通过；记录中保留了首次中断信息。
- `git diff --check` 通过。

复验命令：

```sh
node scripts/starter-economy-smoke.mjs
node scripts/starter-economy-browser.mjs
```

也可在 npm 可用环境使用 `npm run test:starter-economy` 和 `npm run test:e2e:starter`。
