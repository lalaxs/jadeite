# 取消初始加工设备后的经济数值评估

日期：2026-10-23。依据当前工作区代码，而非旧版策划文档。本文是设计审计与候选方案，未修改游戏运行数值，未读写线上或本机正在运行的玩家存档。

## 结论

不能只删除初始赠送的三台设备。当前现金不足以购齐最低生产线，初始高阶员工仍持续形成工资账单，半成品又缺少稳定的系统销售出口。另一端，懂排版、多件取料和直播转卖的玩家，理论利润又显著高于简单加工的玩家。问题是生产、销售、现金周转和成长价格之间没有统一基准，不是某个倍率单独过高或过低。

建议将目标解释为：**正常经营扣完完整成本后稳定小赚；熟练经营收益更好；主动赌石可以单次亏损，但玩家始终有不消耗本金的恢复经营路径。** 若要求每块随机原石、每种镶嵌、每笔高价竞拍都不亏，赌石与选料策略会失去意义。

### 2. 四名初始员工的工资与开局规模不匹配

现有四人的阶位为5/8/3/6，工资合计320+590+190+400=**1,500/登录营业日**。离线跳过的日期不记薪；这不是每离线一天都扣1,500，也不是四小时游戏日扣一次。

不计经营，12,000只够8份工资；买6,800开料机后只够3份。若销售毛利率为20%，每天至少7,500营业收入才能覆盖四人工资，尚未计算其他固定支出。任务现金每天最多1,000，且需完成任务，不能作为无设备时的工资保障。

建议初始改为掌柜自己操作，或仅1名1～2阶助手，日薪100～140。其他员工随着设备、订单量与直播需求再招聘，不能默认用高阶全岗位班底支撑空工坊。直接清空数组不足以实现该规则，现有归一化流程会补回默认员工。

员工降阶也会同时降低工分、速度和碎裂防御，不能只改工资而沿用现在高阶员工的产出。本文960个加工样本使用的是现有初始名册，不能直接当作新名册收益；需要联调掌柜自营能力、来料返工规则与起步工分，再用新名册重跑自营利润。

### 3. 账面估值、实际卖价、成本是三个口径

| 销售出口 | 当前规则 | 能否作为常规保本路径 |
|---|---|---|
| 库存回收 | 估值20%，立即结算 | 不能，只适合止损 |
| NPC批发 | 挂牌10分钟后，最高估值65%；每天最多4件、总6,000 | 不能保证覆盖成本，也不能保证售完 |
| 非成品NPC收购 | 额外要求在线人数≤2 | 不适合用作多人游戏基础收入 |
| 普通订单 | 只收成品；全符合按订单价，部分符合会降价 | 需求、匹配与成交价均需验证 |
| 直播 | 只收成品；价格上限1.8倍估值 | 有较高收益潜力，但非立即保证成交 |
| 玩家之间交易 | 买家额外付2%交易税 | 不能把其他玩家的需求当作系统兜底 |

NPC的6,000额度还存在整件限制：估值10,000的货按65%报价应为6,500，系统会直接过滤，而非自动报6,000。估值高于约9,231且不主动降挂牌的货，可能当天一开始就没有批发报价。

订单的1.25倍是付款上限，不是每件货都能得到的价格。部分符合只给订单价的60%或65%，逾期另乘72%。首件赠料有匹配试单，不能外推成普通货的长期包销价。

### 4. 加工费用目前主要发生在工资、维修与辅材

逐单 stageCost、workerProcessingFee、镶嵌 laborFee 目前均为0。不能把旧配置中的加工费再次加进成本。最低三机每做一轮、精加工一件，应计维修约117；失败重做和多件精加工会继续增加维修。

普通料开料、取件失败可能物料全损；赠料有原主人新手保护。精加工失败通常返还翡翠与辅材，损失主要是时间与耐久。故普通材料的期望利润需要计前两阶段损料风险，赠料流程测试不能替代它。

## 二、原料加工试算：收益对取料与销售过度敏感

运行了两组各480个条件样本：六种种水各80块，重量0.7～2.2kg，使用最低翠捷三机与当前初始员工；一组在5×5位置网格中选估价最高的一个M平安扣，并非中心或随机新手取件；另一组在相同网格中，选择不重叠、废料和裂纹比例均不高于20%的多个M平安扣，平均约5件。余料立即按20%回收。

原料采购成本假设为底价110%加每块200入场费。它是明确的情景假设，不是已模拟中标的实际拍卖价格；同场多买时分摊入场费会降低成本，激烈竞拍与开窗则会增加成本。

以下为**假设货品全部按估值65%卖出后的单块期望经营盈余**，已经扣采购、维修和碎料风险，**未扣工资、机器投资与销售等待成本**。它不是一天内真实到账利润，也未执行NPC件数/金额额度。

| 种水 | 假设平均采购成本 | 只取1件后售完 | 合理排版多件后售完 |
|---|---:|---:|---:|
| 豆种 | 3,071 | -1,395 | +3,010 |
| 糯种 | 5,415 | -2,901 | +1,682 |
| 糯冰 | 9,640 | -4,947 | +1,627 |
| 正冰 | 15,378 | -6,974 | +2,103 |
| 高冰 | 22,442 | -7,704 | +1,097 |
| 玻璃种 | 30,741 | -3,802 | +5,105 |

同一套系统下，新手取一件后回收余料可能明显亏钱，熟练排版的账面利润又很高。多件往往超过NPC每天4件的限制，无法按表内假设当天售完；维持现有四人工资后，跨日销售可能吃掉大量利润。高价件还可能直接超过整件报价限额。因此不能仅看“平均成品总估值大于进货价”就判定经济健康。

这不是所有玩法的最优解搜索：未遍历所有套件、所有位置、继续取余料、主播组合、金属方案与玩家交易；也不是按真实玩家种水分布加权的收入统计。它揭示普通与熟练操作间的收益断层，需要以新手真实操作分布继续验证。

当前原石价格包含重量，开料估值又由原石价格乘种水倍率；取件估价主要使用二维几何采样、色、水与模板倍率，并未直接使用公斤重量。余料则按取件前明料账面值的剩余比例计算。建议统一整块料的材料价值池，取件与余料按同一物理/价值口径扣减，再单列加工增值，避免不同定价体系叠加造成高低档、大小料的收益倒挂。

## 三、需要先修正的几种收益倒挂

1. **黑市买成品再直播，可能比自己加工更优。** NPC常规成品售价约估值98%～105%，直播可报1.3倍。若成交，毛差为估值25%～32%，还省掉生产工序。实际受许可证、三件上架门槛、资金、供货和等待限制，不能视为无门槛无限收入，但足以成为绕过工坊的强路线。应允许薄利转销，避免它同时更快、更安全、利润更高。
2. **低概率不是长期溢价的上限。** 当前直播高价单次购买概率虽被压低，但反复免费开播、持续补货后累计成交概率仍会升高。需要客户需求与系统预算约束，而不是仅将高价概率调低。正常溢价可先试5%～15%；20%以上应消耗稀缺客户/需求。不是简单将高价成交全部关闭。
3. **手镯成功精修也可能降值。** 默认精加工员工擅长普通镶嵌，却不擅长手镯所用的“打磨+修形”。纯公式预览：纯料值50,000，初始工分和设备下毛坯估值65,850，默认师傅标准精修后65,263，成功也下降587，另有维修成本。这源于新工序分数稀释历史总工分，评级降低；建议每步工艺价值独立累计，并提示最适配工人和净增值。
4. **高价料让高级设备过快回本。** 翠捷开料T1/T2/T3价为6,800/20,400/54,400，品质加成为2%/9%/22%。在A级、成交价等于估值的简化模型中，单件纯料值5,000时买T2约68单回本；50,000时约6单；500,000时一单即可覆盖整台采购款。应使用“适用料价档+加值上限”或收益递减，而非无限制百分比乘高价料。实际ROI还受成交折价、销售速度、风险、旧机残值影响。
5. **贵金属不是低价件的稳定升级。** 估值1,000的蛋面，18K爪镶亮光约加值280，却用约570金料；八颗钻石微镶约加值850，却用约2,556辅材。可以保留搭配失误风险，但必须在确认前显示“材料成本、预计到手售价区间、预计增量利润”，不能仅突出加价。
6. **还债会打断有利润的周转。** 欠薪按经营流水扣20%，纾困债再扣10%。850买入、1,000卖出，毛利150；两种债并存只回到现金700，下一单本金反而少150。债务下降意味着净资产未必亏损，但可用现金链会断。应保留下一轮正常采购和工资储备后再还，或改按可分配利润还款。

## 四、建议的第一版经济框架

以每日主动操作约45～60分钟、每个小经营循环8～12分钟为候选基准。下列是需要仿真与玩家验证的目标，不能当成已验证可上线的最终参数。

### A. 无机器也能开始挣钱

开放低效率公共工位，并提供NPC来料加工单：NPC提供料，玩家付少量工位/耗材费用并完成操作，按固定加工报酬结算。来料单失误返料重做，主要损失时间，不让第一次经营靠赌石运气决定生死。公共工位、来料单是新增设计，当前游戏并没有该保障。

基础单的工位和耗材从结算款扣除，允许掌柜亲自完成，不受欠薪员工停工锁限制。这样现金为0时仍有恢复路径；如果要求先垫付工位费或必须由停工员工操作，所谓兜底依然会卡死。

| 指标 | 建议初始候选 |
|---|---:|
| 初始现金 | 保留12,000 |
| 自有机器 | 0台 |
| 初始员工 | 掌柜自营，或1名1～2阶助手 |
| 起步工资 | 0～140/登录营业日 |
| 基础加工单 | 8～12分钟一轮 |
| 每单扣完整成本后净赚 | 120～200 |
| 每小时实际净赚目标 | 600～1,000，扣操作间隔后验证 |
| 周转储备 | 初期至少4,000，后续改按采购规模动态计算 |

示例：单据报酬300，公共工位合计70，耗材30，工资分摊20，净赚180。报酬对合格完成的劳动固定，不按玩家随意抬高的采购成本报销。基础收入可以持续存在，较高利润的优质订单受需求限制，避免出现领完额度就完全无法经营的硬墙。

如果不增加公共工位/来料单，就必须让12,000足够购买完整入门生产线并剩下至少一轮采购本金；单独取消赠机无法实现稳定开局。

### B. 让挣钱压力来自下一次扩张，而不是维持生存

可以保留现有6,800/7,800/8,800作为标准设备，另加需要购买的低效率入门旧机，避免靠大幅增加初始现金解决问题。

| 入门机候选 | 价格 |
|---|---:|
| 旧开料机 | 3,200 |
| 旧取件机 | 4,600 |
| 旧精加工机 | 6,200 |
| 完整入门线 | 14,000 |

完整入门线加4,000储备需要18,000，总计比开局现金多6,000。若首轮赠料净回款与奖励合计约2,500，还需主动挣约3,500，以600～1,000/小时计算约3.5～5.8小时；若完全剔除一次性支持，则需6～10小时。2,500是情景预算，非当前每位新手固定可得；应按实际赠料销售分布校准。

旧机用较低效率、较低加值上限体现定位，不能靠大幅增加碎料率收回优惠。高价原料应提示适用设备与风险。第一台允许用启动金购买，后续设备需要经营积累。购机后现金低于储备线时给明确提示，避免把“买得起”误当作“经营得起”。

设备回本统一按新增真实净利润计算：

`回本有效工时 =（实际采购支出 − 可实现旧机残值）/（升级后每小时净利润 − 原设备/公共工位每小时净利润）`

先将入门设备目标设在约12～24个有效经营小时，中档约24～48小时，再依据游戏期望寿命调整。不能拿整台设备所有产出的营业额除以设备价格，也不能只拿品质百分比算回本。

### C. 常规自营采用完整成本净利率

`完整成本 = 正常进货成本 + 辅材 + 维修摊销 + 工资分摊 + 预期物料损耗 + 渠道费用`

`净利率 =（实际到手收入 − 完整成本）/ 实际到手收入`

| 路线 | 建议目标 | 风险 |
|---|---|---|
| NPC来料基础劳动 | 固定小额正收益 | 失误主要损失时间 |
| 标准明料/合格普通订单 | 到手收入净利率12%～20% | 普通操作也能赚钱 |
| 熟练排版、合适工艺、优质客户 | 净利率20%～30% | 需要操作与经营能力 |
| 自购暗料、竞拍、追高溢价 | 单独建风险分布 | 允许单笔亏损，不能当新手保底 |

例如到手1,000，原料700、辅材40、维修40、工资分摊40、预期损耗30，完整成本850，净赚150，净利率15%。每日做5单净赚750。该示例只说明目标口径，不是当前代码已提供的订单。

普通订单的设计报价应基于正常供货价和合格工艺的标准成本，而不是玩家实际花多少就赔多少；高价竞拍、错误镶嵌、主动低价抛售仍由玩家承担。

### D. 控制富裕速度，先控系统高收益需求，再控投入价格

- 订单、直播、NPC批发的系统支出应一起预算，不能每条渠道都无限接受高利润循环。优质需求额度和普通劳动收入分开：普通劳动始终可恢复经营，高溢价机会有限。
- 新手45～60分钟的正常经营净增现金先以约600～1,000为目标；自有产线后的合理提升由实际效率差测定。衡量时排除赠料、任务、成就与借款。
- 日常现金奖励占稳定经营收益宜控制在约15%～25%。若经营一天才赚800而任务固定送1,000，玩家会更重视领补贴；建议起步阶段奖励预算约200～300/天，成长礼包另记。
- 高级设备、扩大产能、店铺、展示收藏与外观作为主要长期消费。维修和工资有成本意义即可，避免不断抬高固定负担来强行消耗玩家现金。
- 关注“可用现金是否足够下一批进货、是否接近下次升级”，而不是只设一个全等级通用的绝对余额上限。不建议因玩家变富就暗中压低其正常经营收益。

## 五、实现优先级和验收标准

**P0：先保证闭环。** 无机器可做来料单；初始工资缩小；所有阶段有可预期成交出口；正常还债后仍可维持下一单采购；新手任务检查机器和工位可用性。矿区当前关闭，纾困又要求已完成首次销售后再进货的新手循环，不能假设这两者会救回卡住的新号。

**P1：统一价值与利润。** 原料、取件、余料使用同一价值口径；改正手镯成功精修降值；展示辅材真实增量利润；高级设备加值设置适用区间/递减；逐条检验转销与加工收益。

**P2：控制成长与通胀。** 明确系统需求预算、设备新增利润回本、任务/成就注资占比；避免只调收入概率掩盖无限重复出售。

正式改数值后，建议至少运行10,000个账户、覆盖14～30天的行为仿真，包含保守新手、普通经营者、熟练排版者、倒货者与高频玩家。具体次数是下一轮验证计划，本文尚未执行这类长期仿真。

| 验收指标 | 第一版目标 |
|---|---|
| 无机基础劳动 | 不依赖其他玩家成交，扣全部成本后持续正收益 |
| 常规路线低位玩家 | 第10百分位累计经营利润仍≥0，剔除一次性奖励与借款 |
| 流动性 | 绝大多数普通玩家能保留下一批正常采购本金及2个登录营业日工资 |
| 首套入门线 | 在预设普通玩家有效游戏时间内达成，单独统计奖励贡献 |
| 设备升级 | 比较升级前后可实现的每小时净利润，回本不随高价料退化成一单 |
| 销售 | 统计成交等待、日需求用尽、跨日工资，不能只算假设售完 |
| 玩法倒挂 | 同风险同时间下，纯倒货不能长期全面优于核心加工 |
| 尾部与套利 | 检查最快玩家资产增速、重复奖励、无限刷新和重复开播 |
