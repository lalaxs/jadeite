# 员工欠薪宽限与停工

工资仍以北京时间每日 00:00 结算，1～10 阶日薪 100、140、190、250、320、400、490、590、700、820 元，初始四人合计 1,500 元／天。

## 资金与状态

- 零点资金不足时整笔挂账，现金不扣空。首次挂账开始 24 小时宽限，金额不足、小额付款、重连和重启不会刷新截止时间。
- 经营收入按向下取整的 20% 补薪，与现有纾困还款合计最多扣除收入的 30%。覆盖交易行、客户订单、直播、黑市商品／盲盒／服务、库存回收等实际经营回款。退款、返还保证金、纾困金、调试金及任务／成就奖励不参与自动补薪。
- 到期仍有欠薪时，先计入宽限期间已发生的工资，再停工。停工期间禁止新加工、新开播、直播补货及招聘，已有加工和直播正常结束，销售库存、交付订单和领取货款仍可进行。
- 停工期间不新增日工资，离线和停服恢复也按原时间线推演。宽限在日中结束时，最后已经工作的一天按整日结算一次。
- 员工页可手动支付不超过现金及欠薪的金额。欠薪清零后仍保留停工状态，玩家主动点击复工后恢复计薪；复工当天按整日计薪，同一天已计薪部分不会重收。
- 解雇结清当天应计日工资，保留历史欠薪；同一天已计薪工资不会再次计入。
- 旧存档保留自然日结薪游标、欠薪及历史流水；旧欠薪首次升级时获得新的 24 小时宽限，避免升级立即停工。
- 实际支付异常抛出错误，由现有持久化事务回滚，不作为玩家欠薪处罚。

## 界面

员工页显示宽限截止时间、欠薪、预计应付、现金缺口、本次手动补薪金额、支付后余额，以及停工／待复工状态。工坊和直播页面提供停工提示与员工页入口。结算、补薪、停工、复工均有通知。
