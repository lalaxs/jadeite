# 经济调整实施交付记录

2026-10-23。本轮目标是让玩家先靠劳动稳定积累，再购买设备提高收入；稳定收益结论仅覆盖NPC来料加工经营，自购暗料仍有选料、规划、碎裂和销售风险。

## 已落实的规则

- **新账号**：现金12,000、零自有机器、零付薪员工，由不领工资的店主操作。保留赠送原石；原持有人加工赠料免公共工位费。老存档已有机器、员工、库存和资产继续保留，不按新开局清空。
- **公共工位**：开料25、雕件35、精加工40，加工时长为常规时长的1.25倍。工位不进入可出售资产；无机器也能完成生产。
- **来料加工单**：NPC供料，三档基础净收入160／180／200，费用在结算中扣除，不要求玩家垫资。每人同时一单，服务端计时，到时需手动领取；离线等待不自动发钱。重复领取、越权领取及伪造奖励受校验；自有设备参与后，报价计入升级收益与维护费用。
- **购机目标**：入门旧开料机3,200、旧雕件机4,600、旧精加工机6,200，整线14,000；保留标准设备价格。旧机以较低效率和较低加值区分，不靠额外高碎料率惩罚玩家。
- **利润修复**：料值、历史工艺与采购成本在取件及余料间统一分摊，零价值废料不凭空分到钱。各道工艺独立记录，同一道工序重做不复利；成功精修保留已有工艺价值。设备附加值设上限，贵料不能单靠设备倍率一单回本。镶嵌保留贵金属／宝石本体参考价值，再加有限工艺；客户端与服务端共用报价和材料池规则。
- **客户与周转金**：订单、直播共享系统客户额度，初始每日24,000成交额、12件、1,500溢价额度，随等级增长；NPC现成品转售最高按参考估值103%收购，抑制无限倒货。自动还款保护至少4,000周转金，采购额较高或已有雇员时，按近期最大单笔采购加两天工资提高储备。
