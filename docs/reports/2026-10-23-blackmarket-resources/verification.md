# 黑市员工与设备交易验证

> 此为上一版验收记录。后续已按新要求开放初始资源转售与员工、设备卖空，并更新为粗线条简约卡片；当前结果见 [卡片与卖空验收](../2026-10-23-blackmarket-outline-cards/verification.md)。

实现了玩家之间转售已买入的员工和设备，以及 NPC 人才行、设备铺的全服限量供货。NPC 不回收玩家资源。

玩家可从员工详情、工坊设备详情进入黑市上架，支持改价、撤回与分类筛选。成交保留技能经验或型号耐久，直接加入接收方名册或工坊。员工挂牌继续占名额并按登录日计薪；工资及历史欠薪留在原雇主。离线转聘不触发其他员工的新营业日。初始赠送资源不可在黑市转售，员工与设备不能放入盲盒。

## 已通过的验证

- 专项服务端测试：NPC 覆盖与库存、员工和设备转售、工资交接、离线计薪、人数上限、资金不足、忙碌与委托限制、重复上架和购买、改价后的旧报价拦截、批量失败解锁、收益或工资支付失败时双方回滚、撤回与收摊、真实存档往返、空工坊不重新赠送设备。
- 黑市回归：原有物品与服务、NPC 240 笔购买、定时轮换与补货、工艺与货源多样性、余料、规划拆分、离线刷新工具、界面渲染、NPC Socket 交易及 SQLite 重启。
- 关联回归：员工系统、工资政策与 Socket 流程、九项技能详情、花名册、设备系统、设备交易行与双买家竞购、工坊、内存世界存储、JSON/SQLite 存档、共享领域规则和模块结构检查。
- 双账号浏览器验证：1440×900 桌面与 390×844 手机，完成玩家员工及设备买卖、改价、NPC 员工及设备购买、再次挂牌和撤回、SQLite 服务重启恢复。检查了截图，无横向溢出，无浏览器脚本错误。使用临时数据库，没有操作玩家的正式存档。

浏览器结果见 `browser-result.json`，截图保存在本目录。

## 全量验证限制

环境未提供 npm 命令，因此按 package.json 中 test 脚本的相同顺序，递归展开 npm run 后直接使用当前 Node 执行。前 13 项通过，在 auction-halls-unlock-smoke.mjs 的金额断言处停止：同一测试前文扣除入场费 1,400 元，后文却按 2,000 元计算出价后的余额，相差 600 元。没有修改公盘逻辑或这处测试。具体输出保存在 test-suite-result.json。
