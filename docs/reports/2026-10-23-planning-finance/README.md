# 规划草稿与经营账本交付

本轮实现对应已确认的第2、3项方案。开发与验证使用隔离角色、临时存档和独立端口，没有重置正式角色，也没有重启常规游戏服务。

## 规划草稿

- 草稿按当前浏览器、玩家、材料和几何版本分别保存，保留当前布局与上次完成规划版本。
- 添加、删除、尺寸调整、清空及拖动支持50步撤销／重做；一次拖动合并为一步。撤销历史属于当前页面，刷新恢复布局与确认版本。
- ×、Esc、切换材料保留草稿；还原本次修改和恢复上次确认是明确的独立操作。
- 开工失败保留布局，超时保留请求编号等待核对；收到成功回执或权威任务状态确认才清理已提交草稿。
- 等待结果时冻结编辑，重试沿用完整提交参数；迟到回执只处理对应请求，避免误删后续余料草稿。
- 两个窗口各自保存副本，通过显式载入切换；材料几何变化隔离旧副本，存储失败明确提示。

## 成本、成交与批次

- 直接成本由采购实付、加工工位及实际消耗辅材构成；成本构成与总额完整性分别记录。历史未知成本保持未知，赠送材料记录为已知零采购成本。
- 原料拆分、余料和成品继承批次及分摊成本；成交在货品移除前保存成本快照，跨批次订单收入分摊严格守恒。
- 已售毛利、经营费用、来料和技术服务、全损、设备／许可资金、融资和保证金分别累计；工资按所属营业日计一次费用，补薪不再扣一次利润。
- 来料净报酬包含其已有维护结算；受托加工者承担的工位和辅材独立作为服务费用，买方原料只追加约定服务费。委托余料转出按实际归属记录。
- 已交付委托退款会追溯调整原买方的在手、已售或全损成本，支持跨营业日退款；受托方和后续买家无法读取原买方的成本账本。
- 经营收益未计设备折旧，当前营业日未结工资另列预估。
- 库存详情提供已记成本。销售比较模型覆盖订单、直播、挂牌、真实批发报价和回收；目标售价不视作已成交，预估与最终确认分开。
- 批次未清完或成本不完整时不判定最终盈亏。旧物品承接已记成本，账本明确标记启用日期，不伪造启用前历史。
- 所有活跃批次及最近80个结清批次进入界面，归档数量明确显示，累计汇总保留。日明细与去重历史有上限。
