# 服务端生产化交付报告

日期：2026-09-30

项目：翡翠街 Jade Market Prototype

范围：完成部署服务器之前的服务端架构、实现、安全、运维与本地发布验收；未连接或修改远程服务器。

## 结论

本地发布候选已通过全部自动化门槛，可进入最后的远程部署阶段。生产拓扑为单权威 Node.js/Socket.IO 游戏进程 + PostgreSQL + Caddy + 每日备份。浏览器只发送指令和显示结果，现金、库存、交易、随机结果和到期结算都由服务端权威处理。

## 已完成项

### 状态与数据

- 建立可验证的世界快照边界，保留 JSON/SQLite 本地兼容和迁移路径。
- 新增 PostgreSQL 事务检查点、SHA-256 校验、最近多代回退恢复。
- 同事务维护玩家、资金流水、幂等请求、库存所有权和审计投影。
- 新增 JSON/SQLite 到 PostgreSQL 迁移工具，默认拒绝覆盖现有目标，迁移后重读并校验完整世界摘要。

### 写操作一致性

- 所有玩家写事件经过全局串行提交屏障。
- 状态、提示和确认回包只在持久化提交成功后发送。
- 保存失败时恢复操作前世界和 Socket 绑定，清理增量同步版本缓存，并向调用方返回 `PERSISTENCE_FAILED`。
- 首次游客建档、旧会话轮换和离线结算也在持久化后才向客户端发送身份。
- 生产写请求强制 `requestId`，重放不会重复扣款或重复结算。

### 身份与安全

- 游客令牌只保存 SHA-256 摘要，每名玩家最多 8 个可过期、可撤销会话。
- 支持游客绑定账号、scrypt 密码派生、密码登录、单会话退出和全部退出。
- 正式登录使用 `HttpOnly` / `Secure` / `SameSite=Lax` Cookie；不存在的账号也执行同等 scrypt 成本。
- 独立登录限流、HTTP/Socket 限流、Socket 包大小与结构限制、原型污染防护和精确来源白名单已实现。
- 生产模式不注册加钱、解锁、刷物品等调试事件。
- Helmet CSP/HSTS、压缩、请求日志和 Cookie/Authorization/令牌/密码脱敏已启用。
- 正式模式会拒绝缺少 HTTPS 来源、弱管理令牌、占位凭据、关闭持久化或非 PostgreSQL 持久化的配置。

### 实时同步与运行

- 客户端首次获得全量状态，后续可协商 `statePatchV1` 顶层增量补丁。
- 补丁带 `baseVersion` / `stateVersion`，版本中断时客户端自动请求全量重同步。
- 连接加入 `world` 和 `player:<id>` 房间，为后续频道拆分保留边界。
- 定时任务已进入耐久写队列；SIGINT/SIGTERM 会停止接入、排空写入、最终落盘并关闭数据库。

### 可观测与运维

- 新增 `/health/live`、`/health/ready`、`/version` 和受管理令牌保护的 `/metrics`。
- 新增受保护的状态、检查点、强制保存与封禁/禁言管理接口。
- 新增结构化日志、就绪状态、指标和管理操作审计。
- 提供非 root 应用镜像、只读根文件系统、资源/PID/日志上限、PostgreSQL 内网隔离和 Caddy TLS 入口。
- 提供每日自校验 PostgreSQL 备份、保留策略和会覆盖数据库的显式恢复脚本。
