# 成品镶嵌与配石第二版

本版在完整成品 UI 上调整配石规则和固定结构，使用游戏内的 SVG 分层绘制。

| 工艺 | 新方案的配石规则 | 固定方式 |
| --- | --- | --- |
| 爪镶 | 可不配石；戒指左右戒肩各一颗，吊坠或耳坠连接件一颗 | 独立石窝、金属压边与四爪 |
| 包镶 | 不使用配石 | 连续金属包边 |
| 微镶 | 必须选择配石；沿玉件外轮廓排满一圈 | 连续底托、局部石窝、小钉压住石边 |
| 槽镶 | 可不配石；按左右短槽的有效长度排石，两侧等量 | 槽底暗缝、连续金属轨压住石边 |
| 无边镶 | 可不配石；左右各一颗方形配石 | 隐托与细侧边固定 |
| 编绳 | 不使用配石 | 玉件穿孔与编绳 |

微镶数量仍由实际尺寸、轮廓周长、配石粒径和间距决定，包含闭环和碰撞检查。槽镶根据开放短槽长度计算，不能生成满圈。

红宝石采用偏酒红色，蓝宝石采用深蓝色。绘制顺序为石窝与接触暗缝、宝石切面、金属压边与固定爪，固定件遮住宝石边缘。吊扣与耳钩补上连接环。

客户端预览和服务端共用布局函数。服务端重算新提交方案的用料，不信任客户端颗数，也不允许通过旧版本标记创建其他工艺的满圈。已有成品、已保存任务保留原规则和原配石数量；不迁移历史用料。

## 验证

相关 15 个检查脚本通过：精加工模型、成品布局、服务端方案权威校验、预览测试器、镶嵌系统、精加工控制器、玉件渲染与开料、工坊服务与规划、共享领域、响应式、夜间主题、样式拆分、架构质量检查。

成品布局检查覆盖八种题材和三种尺寸的满圈闭环及碰撞，六种镶嵌与三种成品类型的配石规则，预览、报价与绘制数量一致，材料不足不扣料、退料、历史方案，以及隔离测试世界中的真实工坊开工与完工。

浏览器实测中号蛋面吊坠：爪镶 1、包镶 0、微镶 44、槽镶 6、无边镶 2、编绳 0，表单与实际绘制数量相同。中号佛公微镶为 60 颗。以上是当前测试玉件的几何计算结果，不是写死的通用数量。

390×844 手机预览：页面宽度 390，无横向溢出，成品优先显示。浏览器无 error 日志。
