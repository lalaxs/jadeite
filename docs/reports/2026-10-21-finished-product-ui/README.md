# 精加工成品 UI

本次使用代码绘制完整成品，不使用概念效果图作为贴图。

- 共用玉件轮廓，按「背部配件 → 原料裁片与雕刻、抛光 → 正面镶爪与配石」绘制。
- 戒圈、吊坠扣头、耳钩、编绳穿孔分别呈现；六种镶嵌各有底座结构。
- 足金、18K 金、925 银、铂金使用同一套全局材质色板。
- 亮光、柔光、哑光分别控制玉件高光、柔化程度和体积阴影，光源方向不变。
- 新方案沿外轮廓生成闭合满圈，配石粒径固定，按实际尺寸和轨道周长确定颗数，检测转角及相邻配石重叠。
- 服务端按可信玉件重新计算数量；预览、开工扣料、完工组件使用同一结果。旧方案和已有成品仍保留原配石数量。
- 工坊的「镶嵌预览测试」增加方牌、叶子、尺寸和抛光选择，手机端优先显示成品效果。

验证：`node scripts/finished-product-design-smoke.mjs` 覆盖多种题材与尺寸的闭环、碰撞检查、报价与扣料一致、数量防篡改，以及真实工坊开工至完工流程。

另通过精加工模型与控制器、原料裁片、工坊、库存、直播 UI、响应式、夜间主题和架构检查；浏览器检查了四种金属、三种成品连接结构、三种抛光及 390px 手机布局。

`desktop.png` 与 `mobile.png` 是游戏内真实截图。
