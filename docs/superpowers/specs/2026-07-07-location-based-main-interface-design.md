# 地点化主界面与角色侧栏方案

> 日期：2026-07-07
> 范围：网页交互结构、地点入口、解锁/拥有逻辑、交付验收标准
> 状态：待评审

## 背景

当前原型使用左侧导航页签进入工坊、公盘、交易行、订单、直播、藏宝阁和经营报告。左侧还承载招牌、连接状态和排名，右侧总览页显示经营优先级、资产流水线、同行排名和市场战报。

这套结构能快速验证功能，但玩家进入游戏后的第一印象仍像管理后台。新的方向是把功能包装成行业地点，让玩家感觉自己在翡翠街经营，而不是点击一组菜单。

## 设计目标

- 左侧从导航栏改为角色状态栏，常驻显示掌柜身份、资源、库存、时间、倒计时和提醒。
- 右侧默认首页改为地点卡片，地点卡负责承载行动入口。
- 公共地点在未解锁时可见但锁定，点击后提示购买许可或达成条件。
- 私人资产地点在未拥有时不显示；玩家通过交易行获得后才显示入口。
- 第一版保留既有业务 view 和 socket 事件，只新增地点入口层与解锁状态，避免重写玩法。

## 交互方案

### 左侧角色状态栏

左侧不再显示功能页签。它显示玩家身上的信息：

- 掌柜招牌：保留玩家名输入、保存按钮、连接状态和同行排名。
- 核心资源：现金、声望、客户满意、藏宝阁数量。
- 库存阶段：暗料、加工任务、明料/料子、成品、藏品。
- 时间信息：第 X 天 HH:MM、公盘阶段、公盘倒计时。
- 提醒：离线结算、订单可交付、加工即将完成、现金不足、尚未拥有工坊、直播许可未购买。

左栏只做状态和提醒，不承担导航职责。提醒可以包含按钮，但按钮只跳到右侧地点或功能页。

### 右侧地点首页

玩家进入游戏后默认看到地点卡片。地点卡片是世界包装，点击后进入已有功能 view：

| 地点 | 对应 view | 类型 | 初始状态 |
| --- | --- | --- | --- |
| 公盘会场 | `auction` | 公共地点 | 可进入 |
| 交易行 | `market` | 公共地点 | 可进入 |
| 客户茶室 | `orders` | 公共地点 | 可进入 |
| 藏宝阁 | `collection` | 公共地点 | 可进入 |
| 经营账房 | `reports` | 公共地点 | 可进入 |
| 直播间 | `livestream` | 公共地点/许可内容 | 可见但锁定，购买直播许可后进入 |
| 我的工坊 | `workshop` | 私人资产 | 未拥有时不显示，购买工坊后显示 |

地点卡展示：地点名、行业包装文案、当前状态、收益/风险提示、锁定原因和主操作按钮。

### 解锁与显示规则

第一版采用两类规则：

1. 公共地点：未解锁也显示卡片。点击锁定卡片时显示 toast，提示玩家去交易行购买许可或补足条件。直播间属于这一类。
2. 私人资产：未拥有时不显示地点卡。玩家在交易行购买“街角小工坊”后，首页才出现“我的工坊”。工坊相关 socket 行为也检查所有权，避免通过直接事件绕过入口。

这能同时满足“锁定内容给目标感”和“私人资产必须真实拥有”的两种体验。

## 状态与数据设计

新增玩家资产状态：

```js
assets: {
  workshopOwned: false,
  livestreamPermitOwned: false
}
```

服务端负责初始化、归一化和快照输出。前端只根据快照渲染，不自行决定玩家是否真正拥有资产。

新增系统资产挂单：

```js
[
  {
    id: "starter-workshop",
    type: "workshop",
    name: "街角小工坊",
    price: 12000
  },
  {
    id: "livestream-permit",
    type: "livestreamPermit",
    name: "直播经营许可",
    price: 8000
  }
]
```

资产挂单通过交易行展示，玩家购买后写入 `player.assets`。已购买的资产不再出现在该玩家的资产挂单列表。

## 行为约束

- 未拥有工坊时，`startPolish` 和 `extractFromRough` 返回提示，不扣除材料或现金。
- 未购买直播许可时，`scheduleLivestream` 和 `livestreamSell` 返回提示，不移动成品。
- 已拥有的资产重复购买时返回提示，不重复扣款。
- 交易行购买资产使用现有 `spendCash`/`recordLedger` 记账，来源为 `asset`。
- 地点卡点击锁定公共地点时不进入 view，只提示解锁路径。

## 验收标准

- 首页右侧显示地点卡片，而不是功能页签菜单。
- 左侧不显示 `#tabs` 导航；左侧显示资源、库存、时间和提醒。
- 未购买“街角小工坊”时，首页不显示“我的工坊”地点。
- 交易行显示“街角小工坊”，购买成功后首页显示“我的工坊”。
- 未购买直播许可时，首页显示锁定的“直播间”；点击提示去交易行购买。
- 购买直播许可后，“直播间”卡片可进入。
- 服务端阻止未拥有工坊的加工行为和未有直播许可的直播行为。
- `npm test` 通过。
- 启动本地服务后，桌面和移动宽度下无明显文字重叠。
