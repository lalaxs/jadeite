# 直播间信息架构与线框

**日期：** 2026-08-30  
**状态：** 已确认方向，先定 IA，后实现  
**前置：** [2026-07-24 翡翠街直播摊位设计](./2026-07-24-jade-livestream-stall-design.md)  
**范围：** 开播 4 步向导、房主经营看板、访客货盘；不改服务端成交规则

## 1. 目标

在**不改动**开播校验、成交、AI 访问、离线营业等服务端规则的前提下，重组直播页信息架构，降低开播认知负担，让房主看清经营过程，让访客能挑货再买。

### 成功标准

| 角色 | 标准 |
|------|------|
| 新手房主 | 有许可、空闲主播、≥3 成品时，不读说明也能走完开播 |
| 营业中房主 | 回页 5 秒内知道：卖了什么、还剩几件、要不要补货 |
| 访客 | 进房间 30 秒内能切到目标商品并下单 |
| 视觉 | 第一屏读成「一场直播」，不是「经营后台表单」 |

## 2. 页面分区总览

直播页仍分两大区，但标题与职责拆清：

```
┌─────────────────────────────────────────────────────────┐
│  A. 我的摊位（owner）                                     │
│     未开播 → 4 步向导                                      │
│     已开播 → 经营看板（舞台缩小 + 成交/客流 + 补货/关播）     │
│     无许可 → 锁定引导（保持现状）                            │
├─────────────────────────────────────────────────────────┤
│  B. 翡翠街摊位（hall）                                     │
│     排序条 + 房间卡片网格                                   │
│     每卡：舞台讲品 + 货盘缩略条 + 购买                        │
└─────────────────────────────────────────────────────────┘
```

文案调整：

| 现文案 | 新文案 |
|--------|--------|
| 我的摊位 / 正在直播 | 我的摊位 / 本场营业中 |
| 翡翠街实时摊位 / 正在直播 | 翡翠街摊位 / 营业中的房间 |
| 话术风格 | 本场策略（副文案保留稳卖 / 冲高 / 均衡） |
| 步骤 1.5 | 取消半步编号，纳入步骤 2 |

## 3. 开播 4 步向导

### 3.1 状态机

```
locked ──(有许可)──► step1_host
                         │
                    step2_strategy
                         │
                    step3_stock
                         │
                    step4_confirm
                         │
                      live（现有 livestreamRoom）
```

- 仅当前步主内容占屏；顶部固定进度：`主播 · 策略 · 货盘 · 确认`
- 底部 sticky：`上一步` / `下一步`（或最终「开启直播」）
- 草稿保留：`draftHostId`、`draftTalkStyle`、`selectedProductIds`、`priceDrafts`（现有前端状态可复用）
- 校验失败不进下一步：无主播 / 选中 &lt;3 或 &gt;20 / 非法售价

### 3.2 线框 · 步骤 1 选主播

```
┌──────────────────────────────────────────┐
│ 进度 ●○○○  1 主播 · 2 策略 · 3 货盘 · 4 确认 │
├──────────────────────────────────────────┤
│ 推荐主播（大卡）                            │
│  ┌────────────────────────────────────┐  │
│  │ 姓名 · 职位 · T级                   │  │
│  │ 话术/控场/催单 Lv                    │  │
│  │ 预计转化 +X% · 流速 +Y%              │  │
│  │ [已选 · 推荐]                        │  │
│  └────────────────────────────────────┘  │
│  [更换主播 ▾]  → 展开其余空闲主播列表        │
│  忙碌主播灰显不可选                         │
├──────────────────────────────────────────┤
│              [下一步：本场策略]             │
└──────────────────────────────────────────┘
```

要点：

- 默认展示推荐一位大卡；「更换」才展开网格，避免开播页三块卡片墙
- 无可用主播：空态 + 链到员工/招募（文案沿用现有）

### 3.3 线框 · 步骤 2 本场策略

```
┌──────────────────────────────────────────┐
│ 进度 ○●○○                                 │
├──────────────────────────────────────────┤
│ 本场策略（不替代主播，只微调倾向）            │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐     │
│  │ 稳卖走量 │ │ 均衡中庸 │ │ 冲高冲价 │     │
│  │ 略述一句 │ │ 略述一句 │ │ 略述一句 │     │
│  └─────────┘ └─────────┘ └─────────┘     │
│ 预览条：转化 / 流速 / 点赞 相对变化          │
├──────────────────────────────────────────┤
│ [上一步]              [下一步：选择货盘]    │
└──────────────────────────────────────────┘
```

要点：

- 三选一用分段控件或等宽小卡，高度低于现风格大卡
- 预览随选中策略即时更新（复用 `hostBonusesWithTalkStyle`）

### 3.4 线框 · 步骤 3 货盘定价

```
┌──────────────────────────────────────────┐
│ 进度 ○○●○          已选 5/20              │
├──────────────────────────────────────────┤
│ 工具条：[按估值] [估值+5%] [估值+15%]       │
│         作用于已勾选；未勾选不改价           │
├──────────────────────────────────────────┤
│ 列表行（非大方块优先）：                     │
│ □ 图  名称     估值 ¥A                     │
│              直播价 [____]  偏低|持平|偏高   │
│ □ ...                                      │
├──────────────────────────────────────────┤
│ 汇总：5 件 · 总标价 ¥… · 均价相对估值 +6%    │
│ 弱提示：整体偏高可能更慢出货                 │
├──────────────────────────────────────────┤
│ [上一步]     [下一步：确认开播]（≥3 件可点）  │
└──────────────────────────────────────────┘
```

相对估值档位（前端展示，不改成交公式）：

| 直播价 / 估值 | 标签 |
|---------------|------|
| &lt; 0.95 | 偏低 |
| 0.95–1.10 | 持平 |
| &gt; 1.10 | 偏高 |

### 3.5 线框 · 步骤 4 确认开播

```
┌──────────────────────────────────────────┐
│ 进度 ○○○●                                 │
├──────────────────────────────────────────┤
│ 开播摘要                                   │
│  主播：阿翠 · 转化 +12% · 流速 +8%          │
│  策略：稳卖走量                             │
│  货盘：8 件 · 总标价 ¥128,000               │
│  均价相对估值：+5%（持平偏上）               │
│  说明：开播后可补货；售罄自动关播并释放主播    │
├──────────────────────────────────────────┤
│ [上一步]              [开启直播（8 件）]     │
└──────────────────────────────────────────┘
```

确认后仍发现有 `startLivestreamRoom`（items + workerId + talkStyle + requestId）。

## 4. 房主经营看板（live）

与访客大厅卡**分版**，不再共用同一套「大舞台 + 购买」结构。

```
┌──────────────────────────────────────────┐
│ LIVE · 本场营业中                          │
│ 主播 阿翠 · 离线也会继续营业                 │
│ 一行元信息：♥ 点赞 · 在售 6 · 已售 2         │
│ （技能 chip 默认收起，点「主播详情」展开）     │
├──────────────────┬───────────────────────┤
│ 舞台预览（较小）   │ 经营条                  │
│ 当前讲品图+名      │ 本场成交 ¥…              │
│ 1/6 · 轻弹幕       │ 下一波客流约 X 分（可选） │
│                  │ 售罄进度 ████░░ 2/8      │
├──────────────────┴───────────────────────┤
│ 最近成交（滚动 5 条）                       │
│ · AI翠友 买下「冰种平安扣」 ¥12,800 · 2分前  │
│ · 玩家张三 买下「…」 …                      │
├──────────────────────────────────────────┤
│ [补货]（抽屉/面板，默认收起）  [关闭直播]      │
└──────────────────────────────────────────┘
```

要点：

- 补货不默认整页铺开；点「补货」打开面板（容量 = 20 − 在售）
- 关播仍二次确认；文案保持退回库存 + 释放主播
- `nextAiVisitAt` 若快照已有则显示倒计时；没有则省略该行，不造假数据
- 最近成交优先用本场 `room.sales`；不足再回退 `livestreamHistory`

## 5. 访客房间卡 + 货盘

### 5.1 卡片结构

```
┌──────────────────────────────────────────┐
│ LIVE  某某的翡翠直播间                      │
│ 主播行（可选一行） · ♥ · 在售 N · 已售 M     │
├──────────────────────────────────────────┤
│ 舞台（主视觉）                              │
│  成品大图 + 弹幕层 + ‹ ›                    │
│  角标 3/8                                   │
├──────────────────────────────────────────┤
│ 当前讲品 · 名称                             │
│ 参考估值 ¥…     直播价 ¥…     [立即购买]     │
├──────────────────────────────────────────┤
│ 本场货盘                                    │
│ [缩略][缩略][当前][缩略]…  横向滚动           │
│ 点缩略图 → 切到该件为当前讲品（可买）         │
└──────────────────────────────────────────┘
```

### 5.2 购买确认

用页内确认条替代系统 `confirm`：

```
┌──────────────────────────────────────────┐
│ 确认购买「冰种平安扣」？                     │
│ 直播价 ¥12,800 · 估值 ¥11,500 · 余额够/不够 │
│              [取消]  [确认支付]             │
└──────────────────────────────────────────┘
```

### 5.3 大厅

- 标题区旁：排序 `最新开播 | 在售最多 | 成交最热 | 点赞`（前端对 `livestreamRooms` 排序即可）
- 空态：说明 AI 仍接待自己的摊位 + 若可开播给出「去开播」锚点（滚到 owner 区或切到向导）

## 6. 移动端编排

| 场景 | 编排 |
|------|------|
| 开播向导 | 全宽步进；底栏 sticky 上一步/下一步 |
| 房主看板 | 上：元信息+经营数字；中：舞台；下：最近成交；底：补货/关播 |
| 访客卡 | 舞台全宽 → 讲品价与购买可 sticky 底栏 → 货盘缩略条 |
| 大厅 | 默认单列房间卡 |

## 7. 氛围（表现层，不进成交公式）

- 弹幕：随讲品切换淡入/轻位移，避免三行永久钉死
- 成交瞬间：短 toast「成交」+ 点赞数微动（房主看板最近成交插入一行）
- 切品：角标与「当前讲品」文案同步更新
- `prefers-reduced-motion`：停自动轮播与弹幕动效（现有轮播已有相关判断，保持）

## 8. 非本轮范围

- 真人点赞、真人发弹幕、礼物、砍价
- GDD 手动促销话术次数、场次时长结算（可后续挂在步骤 2 扩展）
- 改 AI 购买公式、最低价规则、许可逻辑
- 视频流

## 9. 实现切片建议（确认线框后再动代码）

1. **开播向导壳**：步进状态 + 进度条 + sticky 底栏，内容先搬现有三块
2. **货盘列表化 + 相对估值 + 一键定价**
3. **确认摘要页** 接 `startLivestreamRoom`
4. **房主看板分版** + 最近成交 + 补货抽屉
5. **访客货盘缩略条** + 页内购买确认
6. **大厅排序与空态** + 文案/层级降噪

## 10. 验收清单

- [ ] 开播仅一步一主内容；可前进后退且草稿不丢
- [ ] &lt;3 件无法到确认页或确认按钮禁用
- [ ] 确认页数字与最终 emit 一致
- [ ] 房主卡无购买按钮；有成交额、最近成交、补货/关播
- [ ] 访客可点货盘缩略图切换讲品后再买
- [ ] 购买为页内确认，余额不足有明确提示
- [ ] 桌面与 390px 均可走完开播与购买
- [ ] 现有 smoke：`livestream-ui-smoke` / `livestream-room-smoke` 语义不回退
